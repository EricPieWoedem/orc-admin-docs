# Service Assignment Configuration
This guide outlines how to configure service-specific administrative settings for different entity types within the ORC.GOV portal.

## Navigation to Service Assignment
From the Dashboard:

- Click on Application Management

![service-assignment screenshot](/admin/service1.png)

- Select the Service Assignments card

![service-assignment screenshot](/admin/service2.png)

- Select Entity Type: Choose the entity type for which you want to configure service settings.

![service-assignment screenshot](/admin/service3.png)

- Select Service Type: Pick the specific service to apply configuration settings.

![service-assignment screenshot](/admin/service4.png)

## Configure Service Settings 
The following options are available:

###   1.  Auto Approval
**Purpose:** Enable automatic approval for this service without manual intervention.

**Effect:** Requests for this service will bypass manual review and be approved instantly.

![service-assignment screenshot](/admin/service5.png)

### 2. Approval Levels
**Purpose:** Define the number of approval levels required.

**Options:**

- **Single Level:** Requires approval from one officer role.

- **Double Level:** Requires approval from two distinct officer roles.

![service-assignment screenshot](/admin/service6.png)

### 3. Eligible Officer Roles
**Purpose:** Specify which officer roles are authorized to approve this service.

**Example Available Roles:**

- Supervisor

- Manager

- Director

- Approval Officer

![service-assignment screenshot](/admin/service7.png)


### Save Configuration

Click the Save Configuration button to apply the settings.

![service-assignment screenshot](/admin/service8.png)

⚠️ Note: Changes take immediate effect and may impact system behavior.
