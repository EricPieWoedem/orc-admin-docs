# Overview

This section guides the user through the process of approving changes. Pending approvals can be accessed when an entity has been assigned to the current user or after a successful retrieval.
When an entity needs to be retrieved, the user can follow the same process followed when retrieving registrations.

## Steps

### Pending Approvals tab

- When the user logs in to the dashboard or after retrieval is complete, click the **My Pending Approvals** tab on the horizontal navbar.

![Approve Registrations|2000X1238](/approvechanges1.png)

- Select the **Amendment and Filing Approval** option.

![Approve Registrations|2000X1238](/approvechanges2.png)

- The filter option can be useful in making it easier to find the target entity.

![Approve Registrations|2000X1238](/approvechanges3.png)

- Locate the changed entity to be approved and click the transaction ID under the **Transaction** column.

![Approve Registrations|2000X1238](/approvechanges4.png)

### Review and approval

- After clicking the transaction ID, the user will be taken to a review page.
- Review the details and confirm they are accurate.
- Scroll to the bottom of the page and click the **Approve** button.

![Approve Registrations|2000X1238](/approvechanges5.png)

- A warning popup will appear. Read it carefully, then click **Approve** to confirm.

![Approve Registrations|2000X1238](/approvechanges6.png)

The entity will be approved successfully after completing the steps above.

- Approved changes can be viewed by doing the following:

- Click on **My Approved Transactions** in the nav bar.

![Approve Registrations|2000X1238](/approve.png)

- Here the user can see all changes they have approved.

![Approve Registrations|2000X1238](/approvechanges7.png)
